# 近红外光谱定量建模

这个仓库使用近红外吸光度光谱建立化学成分定量回归模型：以带化验值的校正集训练和评估，用拟合后的最终模型预测无标签测试集。仓库包含可运行的 Python 源码、固定依赖、自动化测试、模型文件、预测结果以及中文图文评价报告。

> **重要：**原始说明没有指明化学成分名称、单位或实际验收阈值；本项目不推断这些信息。测试集没有真实化验值，因此其预测不能用于计算 SEP/MAE，也不能单独证明模型可以投入实际使用。仓库数据仅用于本项目所附数据授权范围；再次分发前请核实适用的许可或授权。

## 数据与任务

数据位于 `近红外光谱数据与说明-2025年/`：

- `校正集/`：320 个 CSV 光谱文件。
- `测试集/`：80 个 CSV 光谱文件。
- `校正集化学成分.xlsx`：校正集实测值，通过工作簿中的**光谱文件名**与 CSV 匹配。
- `数据说明-2025.docx`：随数据提供的任务说明。

每个光谱 CSV 无表头，含 2074 行：第一列为波数，第二列为吸光度。运行时会核验标注文件名集合、数值有效性、光谱长度与波数轴。请勿修改原始文件。样本来源、批次、重复测量组别以及成分单位均未明确记录。

## 模型与评价结果

当前的优化版以全波段 PLS 回归为基础，并在**嵌套交叉验证内层**选择光谱处理和潜变量数。预先规定的逐光谱处理包括原始光谱、标准正态变量变换（SNV）、Savitzky–Golay 一阶导数及 SNV 后一阶导数；每种处理比较 5、10、15、20、25、30 个潜变量。固定外层五折 `KFold(shuffle=True, random_state=42)` 估计泛化误差；各外层训练折内部以四折 `KFold(shuffle=True, random_state=123)` 的合并折外 MAE 选参。缩放和 PLS 拟合均只使用对应训练折。

竞赛指标按指定公式计算，SEP **不扣除偏差**：

- `SEP = sqrt(sum((实际值 - 预测值)^2) / (n - 1))`
- `MAE = sum(abs(实际值 - 预测值)) / n`

| 校正集折外方法 | SEP | MAE | R² |
|---|---:|---:|---:|
| 训练折均值基线 | 6.8504 | 5.1847 | -0.0131 |
| 首版原始光谱 PLSR | 3.8872 | 2.9463 | 0.6738 |
| 优化版嵌套选模 PLSR | **3.4672** | **2.5147** | **0.7405** |

上表源于同一批校正样本的随机外层折外预测，不是独立外部验证。优化版与首版折外 MAE 差值的样本级配对 bootstrap 95% 区间为 0.2272–0.6579，SEP 差值区间为 0.1994–0.6617；此区间仅针对固定折外预测的样本重抽样波动，不涵盖重新训练、拆分、选择和样本相关性的全部不确定性。高含量样本仍有明显低估倾向。

`results_v2/test_predictions.csv` 给出 80 条测试光谱的逐文件预测。没有测试真值，故该文件不是测试集性能报告。随机拆分也无法排除同批次或重复样本跨折导致的乐观偏差。用于实际决策前，应确认成分单位和业务可接受误差，并取得有代表性的独立化验数据；如能获得批次或重复样本标识，应优先进行组外验证。

更多方法、每折结果、误差诊断和局限性见[优化版中文评价报告](模型优化评价报告.md)及[首版中文评价报告](模型评价报告.md)。

## 环境与运行

需要 Python 3.11。建议在仓库根目录创建隔离环境：

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python model.py
python model_v2.py
python -m unittest discover -s tests
```

优化版对比首版时会读取 `results/oof_predictions.csv`，所以请先运行 `model.py`。脚本根据数据说明中的目录读取原始数据，在仓库根目录生成或更新 `results/`、`results_v2/` 和中文报告。固定随机种子并使用单线程数值运算以提高复现性；不同系统的数值库仍可能产生微小浮点差异。加载 `.joblib` 模型时仅使用可信来源的文件。

预测优化版测试集的最小示例：

```python
from pathlib import Path

import joblib

from model import load_data

_, _, wavenumber, _, _, test_spectra = load_data()
saved = joblib.load(Path("results_v2/final_model.joblib"))
assert (saved["wavenumber"] == wavenumber).all()
test_predictions = saved["model"].predict(test_spectra).ravel()
print(test_predictions)
```

该示例需要完整原始数据和仓库根目录下的 `model.py`、`spectral.py`。CSV 结果表同时提供文件名，便于追溯预测对应的光谱。

## 后续改进建议

1. 补充成分及单位、样本来源、批次和重复测量分组信息。
2. 预先规定可接受的 SEP/MAE，并获取独立验证样本及其化验真值。
3. 如需继续改进，先限定候选方法，在训练折内完成预处理与超参数选择；保留未参与模型决策的独立数据作最终验证。

不要根据无标签测试集预测分布调整模型，也不要把已经反复用于选型的外层结果描述为全新、独立的验证结果。
