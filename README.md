# 近红外光谱定量建模

这个仓库使用近红外吸光度光谱建立化学成分定量回归模型：以带化验值的校正集训练和评估，用拟合后的最终模型预测测试集。仓库包含可运行的 Python 源码、固定依赖、自动化测试、模型文件、预测结果以及中文图文评价报告。

> **重要：**原始说明没有指明化学成分名称、单位或实际验收阈值；本项目不推断这些信息。测试集真值由用户另行提供，且经用户明确授权与评估报告一同纳入此私有仓库。训练和模型选择没有使用测试真值；再次发布数据前请核实授权和仓库可见性。

## 数据与任务

数据位于 `近红外光谱数据与说明-2025年/`：

- `校正集/`：320 个 CSV 光谱文件。
- `测试集/`：80 个无标签 CSV 光谱文件。
- `测试集的真实值.xlsx`：用户另行提供并授权存入本私有仓库的测试集实测值；包含样本序号与化学成分含量，需与光谱文件名序号严格对应。
- `校正集化学成分.xlsx`：校正集实测值，通过工作簿中的**光谱文件名**与 CSV 匹配。
- `数据说明-2025.docx`：随数据提供的任务说明。

每个光谱 CSV 无表头，含 2074 行：第一列为波数，第二列为吸光度。运行时会核验标注文件名集合、数值有效性、光谱长度与波数轴。请勿修改原始文件。样本来源、批次、重复测量组别以及成分单位均未明确记录。

## 模型与评价结果

模型 3 在嵌套交叉验证内层比较全谱 PLS、训练折内 VIP 波数筛选 + PLS、SNV-RBF-SVR 和 SNV-Ridge。全谱 PLS 比较原始、SNV、SNV+一阶导数处理及 5/10/15/20 个成分；VIP-PLS 比较 30/75/150/300 个波数及 3/8/15 个成分；SVR 与 Ridge 的缩放、响应变换也在各训练折内拟合。固定外层五折 `KFold(shuffle=True, random_state=42)`；内层四折 `KFold(shuffle=True, random_state=123)` 按合并折外 MAE 选参。筛选、预处理和超参数选择只使用当前训练折。

竞赛指标按指定公式计算，SEP **不扣除偏差**：

- `SEP = sqrt(sum((实际值 - 预测值)^2) / (n - 1))`
- `MAE = sum(abs(实际值 - 预测值)) / n`

| 校正集折外方法 | SEP | MAE | R² |
|---|---:|---:|---:|
| 训练折均值基线 | 6.8504 | 5.1847 | -0.0131 |
| 首版原始光谱 PLSR | 3.8872 | 2.9463 | 0.6738 |
| 优化版嵌套选模 PLSR | **3.4672** | **2.5147** | **0.7405** |
| 模型 3 嵌套算法选择 | **3.4515** | **2.0711** | **0.7428** |

上表源于同一批校正样本、相同随机外层折的折外预测。模型 3 外层训练折内层五次均选择 RBF-SVR，但成分/超参数选择严格处于内层；全量校正数据最终模型为 SNV-RBF-SVR（C=100、gamma=scale、epsilon=0.1）。模型 2 减模型 3 的折外 MAE 差值的样本级配对 bootstrap 95% 区间为 0.1691–0.7033，SEP 差值区间为 -0.4746–0.4837。区间以固定折外预测为条件，未涵盖重新训练、拆分、算法筛选或相关样本的不确定性；由于模型 3 是在观察过前版后探索，该跨版本比较仍属探索性，不是新的独立确认。

模型 3 的测试预测位于 `results_v3/test_predictions.csv`。校正集随机拆分仍无法排除同批次或重复样本跨折导致的乐观偏差。用于实际决策前，应确认成分单位和业务可接受误差，并取得有代表性的独立化验数据；如能获得批次或重复样本标识，应优先进行组外验证。

更多方法、每折结果、误差诊断和局限性见[优化版中文评价报告](模型优化评价报告.md)及[首版中文评价报告](模型评价报告.md)。
模型 3 的候选算法、嵌套验证、图表与来源依据见[模型 3 评价报告](模型3评价报告.md)。

## 外部测试真值评价

如有单独交付且经授权使用的测试标签工作簿，可以运行：

```powershell
python evaluate_test.py --labels "D:\路径\测试集的真实值.xlsx"
```

工作簿须含 `序号` 和 `化学成分含量` 两列；序号须与测试光谱文件名的数字部分一一对应。脚本核验两版冻结预测文件名与磁盘上的 80 个测试光谱相同，并确认真值 ID、预测 ID 集合完全一致且无重复，再按比赛公式计算 SEP（不扣偏差）和 MAE，生成误差诊断及 bootstrap 区间。它不会按表格行顺序配对，不会重训、调参或改写预测。输出写入默认被 Git 忽略的 `results_external/`；本仓库只在用户明确授权后纳入真值工作簿及本次汇总评价报告、诊断图，不包含逐样本真实值/残差导出。首版和优化版均已冻结，二者的测试指标比较属于事后比较，不能再据此选择模型并宣称测试集提供了无偏选模结果。
测试真值此前已用于模型 1/2 的评价，独立确认性用途已经消耗。模型 3 的测试预测在建模和冻结后才作事后核对，不能用该测试核对挑选模型 3 或宣称它是无偏的模型 3 测试估计；详见[模型 3 测试集事后核对](results_v3/test_evaluation.md)。

## 环境与运行

需要 Python 3.11。建议在仓库根目录创建隔离环境：

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python model.py
python model_v2.py
python model3.py
python evaluate_model3_test.py
python -m unittest discover -s tests
```

优化版对比首版时会读取 `results/oof_predictions.csv`，所以请先运行 `model.py`。模型 3 读取模型 1/2 的 OOF 用于同折对比，并单独执行其内层模型选择；会重新生成自己的 OOF、最终模型和冻结测试预测，不读取测试真值。只有模型 3 预测冻结后，才可运行 `evaluate_model3_test.py` 作已消耗测试集的事后核对；不得根据核对结果更改模型。固定随机种子并使用单线程数值运算以提高复现性；不同系统的数值库仍可能产生微小浮点差异。加载 `.joblib` 模型时仅使用可信来源的文件。

预测优化版测试集的最小示例：

```python
from pathlib import Path

import joblib

from model import load_data

_, _, wavenumber, _, _, test_spectra = load_data()
saved = joblib.load(Path("results_v2/final_model.joblib"))
assert (saved["wavenumber"] == wavenumber).all()
test_predictions = saved["model"].predict(test_spectra).ravel()
print(test_predictions)
```

该示例需要完整原始数据和仓库根目录下的 `model.py`、`spectral.py`。CSV 结果表同时提供文件名，便于追溯预测对应的光谱。

## 后续改进建议

1. 补充成分及单位、样本来源、批次和重复测量分组信息。
2. 预先规定可接受的 SEP/MAE，并获取独立验证样本及其化验真值。
3. 如需继续改进，先限定候选方法，在训练折内完成预处理与超参数选择；保留未参与模型决策的独立数据作最终验证。

不要根据无标签测试集预测分布调整模型，也不要把已经反复用于选型的外层结果描述为全新、独立的验证结果。
